# Implementation plans

Add a plan only for an agreed, bounded implementation slice. Link its GitHub issue and relevant Beads steps; state the outcome, dependencies, affected boundaries, verification and completion criteria in English.

Ralphex may prepare and execute these plans under [the development workflow](../development.md). Product decisions belong in product documents and ADRs rather than being silently invented inside a plan. The [Issue #9 workspace plan](issue-9-create-workspace.md) tracks the current slice; completed plans are kept in [completed](completed/).
