# Quality Gates

Действующие обязательные проверки описаны в [docs/development/quality.md](../development/quality.md), полная рабочая политика — в [rules.md](../development/rules.md), точка входа — [AGENTS.md](../../AGENTS.md). Этот путь сохранён для существующих ссылок; отдельного набора gates здесь нет.

Выбирайте проверки по затронутым границам. Проза требует ссылок/якорей, согласованности и `git diff --check`; полный набор нужен для межслойных изменений, миграций и release readiness. Наблюдённые результаты и ограничения указываются в handoff.
