# Место для документа дизайна

Документ дизайна пользователя ещё не предоставлен. В эту папку можно добавить его позже без изменения структуры; будущий файл сейчас не считается существующим или принятым источником.

Добавьте документ в `docs/development/design/`, затем укажите относительную ссылку на него здесь и в [навигаторе](../README.md). Рядом явно укажите статус: черновик, на review или принят пользователем, и какие экраны/вопросы он описывает. Если он меняет существующие UI-контракты, согласуйте расхождения и обновите затронутые источники в соответствующей задаче.

До этого используйте существующие документы:

- [Interface](../../interface.md) — композиция экранов, навигация и контролы.
- [UI guidelines](../../ui-guidelines.md) — правила компонентов, оформления и визуальной проверки.
- [Каталог design](../../design/) — имеющиеся материалы и handoff; их статус проверяется по самому документу.
- [bb adaptation](../../design/bb-stack-design.md) и [ADR-005](../../adr/005-bb-pane-session-chrome.md) — принятые границы адаптации pane chrome.

Содержимое будущего пользовательского документа остаётся за пользователем. Эта папка не задаёт новый визуальный стиль.
