# Compact — верхняя строка действий

Основа — выбранный №3 Compact Precision. «Первый вид» трактуется как Board. Это два состояния одного направления, без внедрения в приложение.

- [Доска](01-compact-board.png): Add View → `+`, Customize Columns → ползунки, меню вида → `…`. Все три действия перенесены в одну верхнюю строку вместе с вкладками. Подписи, рамки и фон кнопок убраны. Отдельной нижней панели действий нет; название Operations остаётся в выбранном workspace слева.
- [Развёрнутая карточка](02-compact-expanded.png): та же компактная шапка; справа иконки Restore to side panel и Close. Управление доской скрыто, как в текущем приложении. Меню выбранной project tab сохраняет Duplicate tab / Restore view / Close view.

Board/Table — виды workspace; Workspace App/Client Portal — отдельные вкладки развёрнутых карточек. Они сохраняются при возвращении на доску. Обычный клик по карточке открывает боковую панель, Expand создаёт вкладку, Restore возвращает карточку в панель. Клик карточки открывает детали. Проекты получаются из папок: создание карточек кнопкой, меню колонок и меню карточек здесь не добавляются. Workspace menu, поиск и настройки сохранены.

Данные те же: Planned — Atlas Website, Studio Library; In Progress — Workspace App, Client Portal; Done — Brand System, Research Notes. В развёрнутом состоянии Workspace App: Status In Progress (только чтение), Add property / Choose type, File tree / README.md / 1 item.

Для будущей реализации: у верхних action icons нет фоновой подсветки, рамки или плашки при наведении. У интерактивных элементов сохраняются доступные имена, достаточная область нажатия, tooltip и видимый keyboard focus. Подписи вкладок и остальных действий не убираются. Статичные PNG показывают внешний вид, но не доказывают hover, взаимодействия, адаптивность или доступность. Это отдельный этап реализации и проверки.

Компромисс: верхняя строка освобождает место для доски, но иконки менее очевидны без подсказок. Основное направление остаётся компактным и светлым. Предыдущие варианты и рабочие данные сохранены.
