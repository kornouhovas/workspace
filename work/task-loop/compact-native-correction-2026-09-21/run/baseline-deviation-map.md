# Native renderer baseline vs selected Compact №3

Source mockups: `outputs/compact-toolbar-2026-09-21/01-compact-board.png` and `02-compact-expanded.png`, both 1486×1059. Baseline: `native-before-board-1486x1059.png` and `native-before-expanded-1486x1059.png`, captured from a separate Electron process loading the repository's built `file://.../dist/renderer/index.html` with the real preload/IPC. CDP set a 1486×1059 CSS viewport and saved PNG. It captures the Electron renderer surface, not the macOS window frame/traffic lights. The already-open user window was not captured because ScreenCaptureKit returned -3811 for the exact app path.

The isolated fixture contains the same six project names and status folders as the mockups, plus a README.md in each project. Workspace App and Client Portal tabs were opened through the UI; Board and Workspace App were captured as active screens. Status colors were set through the real Workspace IPC to yellow/blue/green. Status order is derived from folder scan (Done, In Progress, Planned) and differs from the illustration; reordering it would change status behavior and is outside this task.
