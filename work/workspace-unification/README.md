## Preserved boundaries and limitations

The own backend and current JSON settings/views/properties adapters remain active; Go/any-store integration and Proposed ADR-004's general identity registry are not introduced. Existing project IDs, source bindings, values/history, folder roles, session versions and Electron isolation/sandbox settings are preserved. Native rename is an existing admitted function, not a replacement backend.

[Rename platform status](../../docs/api/workspace-project-rename.md#os-enforcement-and-validation-status) remains explicit: macOS native containment/no-clobber tests passed; Windows cross-compiles but native adversarial acceptance is outstanding; Linux currently refuses rename before mutation because its safe implementation is incomplete. Existing `workspace-2re`/`workspace-mcc` platform/acceptance tasks are not closed by this consolidation. Historical security/design findings and unavailable platform acceptance are not reclassified as passed.
