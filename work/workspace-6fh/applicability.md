## Measurement interpretation

Generic defaults are measured in the explicit isolated Controls fixture rendered by the same Electron executable, preload sandbox and production primitive modules. Product chrome overrides are measured separately; 28px tabs and 24–32px inline controls are intentional existing row contracts. Generic defaults are not claimed to be the geometry of every product control. Table hover is muted/50, Button uses foreground/background, menu hover uses state-hover, and transparent surface mixes use OKLab as specified.

Not applicable rows cite the current PRD/product boundaries; they do not introduce chat, cloud, terminal, IDE or mobile surfaces. No source document was edited. All source sections are classified; references describe the implementation and completed checks, not a claim of full assistive-technology certification.

Locale switching is display-only: `locale/report.json` measures zero IPC calls, zero loading transitions and zero blank frames while the language changes; later legitimate loads use the current language. Native matrix, measured styles and fixture states are indexed by [final report](final-report.md) and the SHA256 freeze inventory.
